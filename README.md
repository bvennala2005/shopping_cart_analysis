# shopping_cart_analysis using python
**Project Overview**

This project is a simple Python shopping cart analysis system built for beginners to practice:

Functions
Dictionaries
Lists
Loops
Conditional Statements

It analyzes shopping cart data and performs multiple operations like billing, product comparison, category analysis, and quantity calculations.

**Features**
Total Bill Calculation
**Calculates the complete shopping cart bill based on:**
Price × Quantity
**Most Expensive Product**
Finds the highest-priced product in the cart.
**Cheapest Product**
Finds the lowest-priced product.
**Average Product Price**
Calculates average price of all products.
**Total Quantity**
Counts total number of purchased items.
**Electronic Category Bill**
Calculates total bill only for electronic products.
**Display Electronic Products**
Shows all products under electronic category.
